The app does not read NIST library spectra. The localhost bridge sends eligible reconstructed spectra to licensed NIST MS Search and returns candidate names, original ranks, MF/RMF, and related metadata from SRCRESLT.TXT. Review is staged as: NIST candidates (immutable snapshot) → deterministic QC (optional) → external-model advice (optional) → human disposition. No review stage deletes the raw ranked candidates or overwrites their original scores.
