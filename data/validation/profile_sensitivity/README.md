# Full-length profile sensitivity and sparse-spectrum QC

The same 7,680-scan validation mzML was processed with the archived default, permissive and selective presets. The reports provide component counts, reconstructed-ion distributions, automatic-search eligibility at the v1.3.1 default of three ions, matched-apex spectral cosines, the recorded browser environment, and equivalence to the archived default reference.

These are extraction-level checks. They do **not** report NIST identification agreement because no licensed NIST library or licensed result is included in the public validation. Laboratories that run all three profiles with the same licensed library and search configuration can use `scripts/compare_profile_nist_exports.py` to compare selected names, original ranks, five-group annotations, and nine-class annotations.
