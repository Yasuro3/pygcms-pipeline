# PyGCMS Pipeline v1.4.1 RC: 分類表と解析上の注意

## 1. 保存済みFA結果に付けた探索的A/OAr/C/N/F/S/R群

| 記号 | 英語 | 日本語 | MF700記録数 | MF800記録数 |
| --- | --- | --- | ---: | ---: |
| A | Aromatic hydrocarbons | 芳香族炭化水素 | 385 | 150 |
| OAr | Phenolic / oxygenated aromatic | フェノール・含酸素芳香族 | 72 | 25 |
| C | Carbohydrate-related | 糖関連・フラン由来候補 | 5 | 2 |
| N | Nitrogen-related | 含窒素関連候補 | 117 | 17 |
| F | Aliphatic / lipid-related | 脂肪族・脂質関連 | 50 | 33 |
| S | Sulfur-bearing | 含硫黄化合物 | 22 | 10 |
| R | Residual / unresolved | 残余・未分類 | 727 | 146 |

**F = Aliphatic / lipid-related**。Fatty Acid（脂肪酸）だけを表す分類ではありません。

件数は保存済みFA 12測定の NIST 第一候補に依存するQC通過「成分記録数」です。化合物の確定同定数、濃度や含有量ではありません。
分類エンジンの出力列に欠落があるため、この保存済み候補名ベースの群分けをネイティブ分類モデル2.2.0の完全な再実行結果と同一視しないでください。

## 2. EGA照合用の探索的再分類

| コード | 名称 | 例 | 注意 |
| --- | --- | --- | --- |
| AH | アルキル芳香族・PAH様 | トルエン、キシレン、ナフタレン類 | 探索的候補名からの再分類。芳香族構造の個別確認が必要 |
| PH | フェノール類・含酸素芳香族 | フェノール、クレゾール類 | 異性体は未確定 |
| CF | フラン・糖由来候補 | フラン、フラノン、フランジオン | 糖類からの生成を証明する群ではない |
| AL | 脂肪族・脂質様 | アルケン、脂肪族アルコール、脂肪酸 | Fと重なるが分類ルールは同一ではない |
| OX | 低分子含酸素生成物 | 酢酸、アセトン、シクロペンテノン | 熱分解・二次生成・熱脱着の区別が必要 |
| N | 含窒素 | ニトリル、ピリジン、アミド | 不自然なライブラリ候補あり |
| S | 含硫黄 | チオール、チオフェン | 少数候補、初期保持などを再点検 |
| TI | テルペノイド・ステロイド様候補 | カロテノイド様、環状天然物様候補 | NISTの不自然な高分子候補を含み、確定起源ではない |
| PL | フタル酸・可塑剤候補 | フタル酸無水物、DEHP | ブランク／実験由来アーティファクトの検証を優先 |
| MX | その他・未整理 | 化学的解釈未確定 | 主解析からの除外条件に注意 |

ALとFは完全には同義ではありません。上記の再分類は論文本文の既定分類やv1.4.1エンジンを置き換えるものではありません。
Rを除いた6群内百分率とRを含めた全QC候補内百分率は分母が異なります。
NIST MFは同定確率ではありません。化合物の名前や環境起源の確認には標準物質、保持指標、ブランク、EIスペクトルの再確認が必要です。
EGAの温度換算は15 °C/min、初期温度100 °Cは仮定です。EGA-群相関はn=4の探索に留めてください。
